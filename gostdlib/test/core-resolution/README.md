# Checker Resolution Only

This declaration supplies the opaque public `RawPointer` import while the
standalone provider is checked and certified with TS-Go. It is not a runtime
implementation, a marker selector, or an output dependency. Provider assembly
copies only production source; canonical checking resolves `@tsonic/core`
through the shared Tsonic owner and finalizes its exact facts.

The provider certificate exact-joins unsafe-pointer callable positions to this
import's declaration identity. A private same-shaped provider declaration does
not satisfy that join. Executable pointer values must come from generated
canonical operations, never from this declaration or an assertion.
