# GoToTS

A general Go-to-TypeScript compiler.

The authoritative specification is [`docs/spec/`](docs/spec/README.md) — six
Markdown files forming one normative contract. Everything else in this
repository is evidence or implementation subordinate to it.

Status: cleanroom rebuild in progress from an empty baseline. See
[`docs/cleanroom-admission-ledger.md`](docs/cleanroom-admission-ledger.md) for
the retired-architecture provenance and component-admission record.
